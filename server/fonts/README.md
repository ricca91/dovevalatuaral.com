# Font delle anteprime social

Font locali distribuiti sotto SIL Open Font License 1.1 (licenze incluse).
Famiglie coerenti con Draftsman; nessun caricamento font di rete durante il render.

- Archivo: https://github.com/google/fonts/tree/main/ofl/archivo
  `Archivo[wdth,wght].ttf`, scaricato il 13 settembre 2026.
- JetBrains Mono: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono
  `JetBrainsMono[wght].ttf`, scaricato il 13 settembre 2026.

Le copie TTF servono solo al renderer Node e non sono pubblicate come asset del
sito. Il browser mantiene i font incorporati in `draftsman.css`.
